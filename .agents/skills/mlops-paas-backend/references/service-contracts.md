# Service contracts

## IDs

Keep Build, project, model version, training job, deployment, monitor, and run UUIDs in distinct fields. Never overload one environment variable for multiple resources.

## Callbacks

- Resource UUID appears in the callback path.
- Authenticate with the intended reporter secret/capability.
- Supply `Idempotency-Key` for retriable operations.
- Treat duplicate terminal callbacks as success/no-op.
- Reject cross-resource or late state resurrection.

## Storage

- Jobs receive presigned URLs scoped to one object and operation.
- Upload/download timeouts are bounded.
- Safe extraction rejects traversal, absolute paths, and unsafe symlinks.
- Object keys are generated by the Control Plane, not tenant input.

## Runtime logs

Redis log streams are keyed by resource type and UUID and support cursor polling. They are transient presentation state; PostgreSQL status remains authoritative.

## Configuration

Secrets enter trusted services through environment/Secret resources. Tenant jobs receive explicit minimal values. Inspect `.env.example`, Compose, Kubernetes ConfigMaps/Secrets, workflow templates, and tests together before adding a variable.
